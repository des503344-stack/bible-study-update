연결된 원고나 [[링크]]가 아직 없습니다.
원고에 [[주제어]] 또는 [[창1:1]]을 입력하고 저장하면 지식 그래프가 자동으로 그려집니다.
⌨️ 단축키 확인 및 나만의 단축키 설정
변경할 기능의 단축키 버튼을 클릭한 뒤 원하는 키 조합(예: Ctrl+Shift+L, Alt+H)을 누르면 즉시 저장됩니다.
입력 대기 중 ESC로 취소, Backspace로 단축키를 해제할 수 있습니다. (한글/영문 입력 상태 모두 지원)
🅰️ 내 폰트 관리 (직접 추가 · 원드라이브 동기화)
기기에서 .ttf / .otf / .woff2 폰트 파일을 선택해 바로 추가하거나, 원드라이브 BibleStudy/성경DB/폰트 폴더에 넣어두면 모든 기기에서 자동 동기화됩니다.
